# alexjwick.github.io

Redirects alexjwick.github.io to [www.alexwick.co](https://www.alexwick.co). The site's source is in
[alexjwick/alexwick.co](https://github.com/alexjwick/alexwick.co).

`CNAME` sets www.alexwick.co as this GitHub Pages site's custom domain, which makes GitHub
redirect every alexjwick.github.io URL there with the path kept. `index.html` and `404.html` are a
fallback in case that redirect ever stops. `.nojekyll` makes Pages serve the files as-is.
